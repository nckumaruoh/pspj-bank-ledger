# Personal Bank Ledger and Statement Generator

A completed PSPJ Java console application built in visible weekly increments. It demonstrates programming techniques through a fictional personal ledger; it is **not** a real banking system, financial product, or source of financial advice.

## Completion status

All twelve weekly stages are present. Each `week-XX` folder contains runnable Java source, a procedure, a trace, and captured console-output proof. Week 11 also generates and reloads the small fictional `ledger.csv` sample at runtime.

The stages intentionally use small, self-contained instructional samples: Week 4–5 illustrate a two-transaction menu sequence, Week 7 illustrates validation from a fresh sample balance, and Weeks 3/6/11/12 illustrate a three-transaction statement. They are examples of the relevant programming technique rather than a single persisted real-world account.

## Twelve-week PSPJ execution plan

1. Define problem statement, fictional sample data and console output.
2. Apply arithmetic to fixed sample deposits and withdrawals.
3. Use a loop to print a sequential mini statement.
4. Add loop-driven workflow and menu.
5. Extract reusable methods.
6. Store and search data using arrays.
7. Improve modularity and test edge cases.
8. Apply recursion where it has a meaningful role.
9. Model domain entities with classes and objects.
10. Handle invalid input and exceptions.
11. Persist records to files.
12. Use collections and streams for a final report.

## Weekly submission rule

Each week is committed separately after compilation and a console-output comparison. See [the final documentation](docs/FINAL_DOCUMENTATION.md) for the run commands and evidence map.
