# Week 9 procedure — account and transaction objects

1. Define an `Account` class with private holder and balance fields.
2. Define a `Transaction` class with private type and amount fields.
3. Construct one fixed sample account and one fixed sample transaction.
4. Read values through getters and print a concise statement.

Compile and run with `javac BankWeek09.java` followed by `java BankWeek09`.

> This is an academic ledger simulation, not banking advice or a real financial system.
