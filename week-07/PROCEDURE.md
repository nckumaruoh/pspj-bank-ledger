# Week 7 procedure — modular ledger and edge cases

1. Store ledger balance inside an object.
2. Accept only positive deposits and withdrawals.
3. Reject a withdrawal that exceeds the balance.
4. Confirm that rejected transactions do not change the balance.
5. Print the final balance.

Compile and run with `javac BankWeek07.java` followed by `java BankWeek07`.

> This is an academic ledger simulation, not banking advice or a real financial system.
