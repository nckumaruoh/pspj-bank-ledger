# Week 10 procedure — validation exceptions

1. Parse an amount inside a helper method.
2. Reject nonnumeric text with a custom checked exception.
3. Reject zero or negative numeric values with the same exception type.
4. Catch the exception in the calling loop and print the reason.

Compile and run with `javac BankWeek10.java` followed by `java BankWeek10`.

> This is an academic ledger simulation, not banking advice or a real financial system.
