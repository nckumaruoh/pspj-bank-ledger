# Week 4 procedure — loop-driven ledger menu

1. Display the core ledger-menu actions.
2. Process one deposit and one withdrawal with a `while` loop.
3. Update the balance after each valid transaction.
4. Print the new balance and processed transaction count.

Compile and run with `javac BankWeek04.java` followed by `java BankWeek04`.

> This is an academic ledger simulation, not banking advice or a real financial system.
