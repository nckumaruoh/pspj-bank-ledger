# Week 11 procedure — sample CSV persistence

1. Create a small fictional CSV statement with a header and three transactions.
2. Write it as `ledger.csv` in the run folder.
3. Read the file back line by line after the header.
4. Parse each change and recompute the closing sample balance.

Compile and run with `javac BankWeek11.java` followed by `java BankWeek11`.

> The program overwrites a deliberately fictional local sample file. It is an academic ledger simulation, not banking advice or a real financial system.
