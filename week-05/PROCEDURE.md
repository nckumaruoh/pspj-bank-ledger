# Week 5 procedure — reusable ledger methods

1. Create a method for deposits.
2. Create a guarded method for withdrawals.
3. Create a common currency formatter.
4. Call the methods for one valid deposit and withdrawal.

Compile and run with `javac BankWeek05.java` followed by `java BankWeek05`.

> This is an academic ledger simulation, not banking advice or a real financial system.
