# Week 12 procedure — final collection and stream report

1. Store fictional transactions in a `List` of objects.
2. Use streams to calculate the closing balance, deposits, withdrawals, and largest debit.
3. Group transactions by their educational category with `groupingBy`.
4. Print the final console report and compare it with the saved output proof.

Compile and run with `javac BankLedger.java` followed by `java BankLedger`.

> This is an academic ledger simulation using fictional data. It is not a bank, financial product, or source of financial advice.
