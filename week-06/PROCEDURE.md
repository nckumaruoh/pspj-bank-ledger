# Week 6 procedure — statement arrays and search

1. Store transaction labels and values in matching arrays.
2. Search the labels for `Rent`.
3. Scan negative values to find the largest debit.
4. Print the lookup and debit result.

Compile and run with `javac BankWeek06.java` followed by `java BankWeek06`.

> This is an academic ledger simulation, not banking advice or a real financial system.
