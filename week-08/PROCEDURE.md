# Week 8 procedure — recursive expense total

1. Store three fixed sample expense values in an array.
2. Write `sumExpenses` with an index parameter.
3. Stop at the base case when the index reaches the array length.
4. Add the current expense to the recursive result and print the total.

Compile and run with `javac BankWeek08.java` followed by `java BankWeek08`.

> This is an academic ledger simulation, not banking advice or a real financial system.
